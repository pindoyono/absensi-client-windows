# 📋 In-Field Matching Accuracy Test (REQ-EMBEDDING-004)

Dokumen ini mencatat hasil pengujian akurasi face matching di lapangan (gerbang sekolah) dengan siswa asli.

---

## 1. Metodologi Testing

- **Peserta:** 50+ siswa
- **Prosedur:**
  - Enroll 50+ siswa di kiosk.
  - Setiap siswa melakukan 5x scan di waktu berbeda (pagi, siang, sore).
  - Catat: match result, nama siswa, jarak (distance), dan waktu.
- **Target:** Akurasi ≥ 95%, False Positive Rate ≤ 1%.
